## Featured projects

### 🛒 [Smart Shopper](https://github.com/d3c0r1x/smart-shopper) · [live demo](https://d3c0r1x.github.io/smart-shopper/)

AI shopping assistant for Ozon, Yandex Market and Wildberries.

Text or photo → real marketplace data → filtering/ranking → review analysis → recommendation.

**Shows:** LLM integration, grounding, hybrid search, API adapters, Telegram + React, session state, fallbacks, tests.

### ⚙️ [AI Automation Platform](https://github.com/d3c0r1x/ai-automation-platform)

Task-running automation MVP: natural language → validated plan → queue → tools → progress → report, with a human approval gate before external side effects.

**Shows:** FastAPI, PostgreSQL/SQLite, Redis, workers, Playwright, typed tool contracts, SSE, Docker and CI.

### 💰 [Finance Bot](https://github.com/d3c0r1x/finance-bot)

Local-first Telegram finance assistant. Receipt photos are processed by a local Vision model and independently checked with Tesseract and arithmetic rules. Includes budgeting, debt tracking, reports and a desktop panel.

**Shows:** local AI, Vision/OCR, data validation, scheduled jobs, SQLite and testable business logic.

### 🎨 [Paint by Numbers](https://github.com/d3c0r1x/paint-by-numbers) · [live demo](https://d3c0r1x.github.io/paint-by-numbers/)

Browser app that converts a photo into a paint-by-numbers image and lets the user paint it directly in the browser.

**Shows:** React/TypeScript, Canvas, Web Workers, image-processing algorithms, IndexedDB, performance work and SwiftUI/PencilKit experimentation.
